
# 📊 Social Media Engagement Dashboard

An end-to-end multi-platform social media analytics project built to analyze 10,000+ posts, track engagement patterns, and provide actionable insights for digital marketing strategies.

---

## 🛠️ Tech Stack & Tools Used
* **Python (Google Colab):** Data cleaning, preprocessing, and exploratory data analysis (`social_media_cleaned_dataset_10k.xlsx`).
* **Excel / CSV:** Initial multi-platform dataset storage and structuring.
* **Power BI Desktop:** Designed a professional 2-page interactive dashboard featuring Glassmorphism UI, custom KPI cards, slicers, treemaps, and trend timelines.
* **GitHub:** Version control and portfolio hosting.

## 🚀 Key Features & Workflow
1. **Data Ingestion & Cleaning:** Processed a 10K multi-platform record dataset using Python scripts in Google Colab.
2. **Interactive Filtering:** Built dynamic slicers (Traffic Source, Account Type, Day of Week, Media Type, Performance) for custom granular views.
3. **Visual Aesthetics:** Implemented modern Glassmorphism banners and cohesive color-coded charts to ensure a corporate presentation look.
